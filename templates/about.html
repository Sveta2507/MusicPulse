SEMANTIC WEB PROJECT

Музика як пов'язані дані

«UA Music Pulse» показує, як із відкритого графа знань створити зрозумілий та практичний цифровий продукт.

01

Мета

Об'єднати відомості про сучасних українських виконавців і дати змогу швидко шукати, фільтрувати та досліджувати музичну сцену.

02

Open Linked Data

Дані отримуються SPARQL-запитом із Wikidata. Кожен виконавець має глобальний QID, а локальний RDF-ресурс пов'язано з ним через owl:sameAs.

03

Надійність

SQLite пришвидшує запити, а JSON-знімок забезпечує автономний запуск. Ручне оновлення не руйнує чинні дані, якщо мережа недоступна.

04

Відкритий результат

Каталог можна одержати як JSON API або завантажити у форматі RDF/Turtle для повторного використання іншими семантичними системами.
